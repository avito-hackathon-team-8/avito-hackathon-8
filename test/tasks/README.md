# Сценарии API задач

Чёрные ящики тесты для `/api/v1/tasks`. Они используют запущенный бэкенд по HTTP и подготавливают изолированных тестовых пользователей в контейнере. 

## Запуск

Из корня проекта:

```sh
cp .env.example .env # если .env ещё не существует
make up
node --test test/tasks/*.test.mjs
