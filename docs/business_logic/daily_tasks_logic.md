# Система дневных задач

## Назначение

Система дневных задач предназначена для ежедневного вовлечения пользователя в активность внутри приложения. Выполняя простые и понятные действия, пользователь зарабатывает листья, которые необходимы для развития питомца и участия в лидерборде. Задачи обновляются каждый день, что создаёт ритуал ежедневного посещения приложения и поддерживает интерес пользователя на постоянной основе.

---

## Общие принципы

- Пользователь может выполнять ежедневные задачи для получения листьев.
- Задачи обновляются ежедневно в установленное время для всех пользователей одновременно.
- Доступность задач зависит от уровня питомца:
  - С 1 уровня доступны первые две задачи.
  - С 5 уровня открывается третья задача.
  - С 10 уровня открывается четвёртая задача.
- После выполнения условия пользователь отдельно забирает награду за конкретную задачу.
- За получение награды начисляются листья в следующем размере:
  - Задачи 1 и 2: по 45 листьев каждая.
  - Задача 3: 50 листьев.
  - Задача 4: 60 листьев.
- Награду за каждую задачу можно получить только один раз в течение дня.
- После выполнения всех доступных задач пользователь не может выполнить их повторно до следующего обновления.
- На главной странице отображается количество выполненных задач (например, «Выполнено: 2/4»).
- В разделе «Задания» пользователь видит полный список всех доступных задач, их условия и прогресс выполнения.

### Статусы задания

| Статус | Значение |
|--------|----------|
| `LOCKED` | Задание пока недоступно из-за уровня питомца. |
| `IN_PROGRESS` | Условие задания ещё не выполнено. |
| `COMPLETED` | Условие выполнено, награду можно забрать. |
| `CLAIMED` | Награда уже начислена. |

В счётчике вида «2/4» выполненными считаются задания в статусах `COMPLETED` и `CLAIMED`.
Знаменатель всегда равен четырём и включает задания, заблокированные по уровню.

## Типы задач

Поле `type` принимает один из следующих типов:

| Код API | Название | Что засчитывается в прогресс |
|---------|----------|------------------------------|
| `OPEN_NOTIFICATIONS` | Открыть уведомления | Каждое подтверждённое открытие уведомления пользователем увеличивает `currentCount` на 1. |
| `ADD_TO_FAVORITES` | Добавить в избранное | Каждое объявление, добавленное пользователем в избранное, увеличивает `currentCount` на 1. Удаление объявления из избранного не уменьшает уже полученный прогресс. |
| `PUBLISH_LISTING` | Опубликовать объявление | Каждое объявление, которое успешно прошло публикацию, увеличивает `currentCount` на 1. Черновик не учитывается. |
| `BOOST_LISTING` | Поднять объявление | Каждое успешное применение услуги поднятия к объявлению пользователя увеличивает `currentCount` на 1. |
| `LEAVE_REVIEW` | Оставить отзыв | Каждый успешно опубликованный отзыв о сделке или пользователе увеличивает `currentCount` на 1. Черновик отзыва не учитывается. |
| `COMPLETE_DEAL` | Завершить сделку | Каждая завершённая покупка или продажа увеличивает `currentCount` на 1. Созданная, отменённая или незавершённая сделка не учитывается. |
| `ORDER_WITH_DELIVERY` | Заказать с доставкой | Каждый успешно оформленный заказ с Авито Доставкой увеличивает `currentCount` на 1. Заказ без доставки не учитывается. |

Для всех типов действуют общие правила:

- Требуемое количество действий приходит в `targetCount`; тип задачи сам по себе его не задаёт.
- Бэкенд учитывает только подтверждённые события и не должен повторно считать одно и то же событие.
- `currentCount` не превышает `targetCount`. После достижения цели статус меняется на `COMPLETED`.
- Действия, выполненные до начала текущего дня или пока задача имеет статус `LOCKED`, в дневной прогресс не входят.

---

## Логика обновления задач

1. В определённое время каждый день задачи сбрасываются для всех пользователей.
2. Формируется новый набор задач на текущий день.
3. Задачи могут быть как однотипными (например, всегда «Опубликовать объявление» и «Завершить сделку»), так и случайными из пула типов.
4. Прогресс выполнения задач обнуляется, и пользователь начинает выполнение заново.

## Примеры задач

| Уровень | Задача | Условие | Награда |
|---------|--------|---------|---------|
| 1 | Открыть уведомления | Открыть 5 уведомлений | 45 листьев |
| 1 | Добавить в избранное | Добавить 3 объявления в избранное | 45 листьев |
| 5 | Опубликовать объявление | Опубликовать 1 объявление | 50 листьев |
| 10 | Завершить сделку | Совершить покупку или продажу | 60 листьев |
