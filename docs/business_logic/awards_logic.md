# Система наград

## Назначение

Система наград предназначена для мотивации пользователя к активному взаимодействию с приложением. Выполняя задания, повышая уровень питомца и участвуя в соревновании с другими игроками, пользователь получает ценные бонусы, которые можно использовать на платформе Авито. Награды делают игровой процесс осмысленным и приносят реальную пользу, превращая виртуальные достижения в практические выгоды. 

## Общие принципы

Пользователь может получать награды в приложении тремя основными способами:

1. Повышение уровня питомца.
2. Открытие сундука (доступно с 10 уровня).
3. Вхождение в топ-3 лидерборда (обновляется раз в месяц).

Все полученные награды становятся активными и отображаются в разделе «Награды».  
Каждая награда имеет срок действия. После использования или истечения срока она
остаётся в разделе «Награды» как неактивная, чтобы пользователь мог снова открыть
её карточку и посмотреть сведения о награде.

При получении любой награды система отправляет соответствующее уведомление в раздел «Уведомления».

## Типы наград

Поле `type` принимает один из пяти типов:

| Код API | Название | Что получает пользователь |
|---------|----------|----------------------------|
| `AVITO_BONUS` | Бонусы Авито | Фиксированное количество бонусов, которыми можно частично или полностью оплачивать поддерживаемые платные услуги Авито. |
| `FREE_DELIVERY` | Бесплатная доставка | Возможность оформить указанное количество заказов без оплаты стоимости доставки. |
| `FREE_PROMOTION` | Бесплатное продвижение | Бесплатное применение поддерживаемой услуги продвижения объявления на указанный срок или указанное количество раз. |
| `PROMOTION_DISCOUNT` | Скидка на продвижение | Процентная скидка на поддерживаемые платные услуги продвижения объявлений. |
| `DELIVERY_DISCOUNT` | Скидка на доставку | Процентная скидка на стоимость Авито Доставки для поддерживаемых заказов. |

Код типа определяет только назначение награды. Конкретный номинал, процент, количество
применений и ограничения задаются конфигурацией награды и отражаются в её `title`.
Например, две награды типа `PROMOTION_DISCOUNT` могут давать скидку 10% и 20%.

Каждая выданная награда является отдельным экземпляром с уникальным `rewardId`, одним
`type`, названием и сроком действия. Даже две одинаковые по типу и номиналу награды
должны иметь разные `rewardId`.

## Отображение наград

### Раздел «Награды»

В этом разделе отображаются все награды, сгруппированные по типам. Активные
награды доступны для использования, использованные и просроченные помечаются
как неактивные.
Для каждой награды показывается:

- Название награды.
- Группа (тип).
- Срок действия (дата истечения).
- Состояние: активна, использована или просрочена.

Использованные и просроченные награды не скрываются из списка.
