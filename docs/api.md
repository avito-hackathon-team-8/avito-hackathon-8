# API

Все пользовательские endpoint-ы, кроме health-check и методов авторизации,
требуют заголовок:

```text
Authorization: Bearer <JWT>
```

Внутренние endpoint-ы используют заголовок:

```text
X-Service-Token: <INTERNAL_SERVICE_TOKEN>
```

Все даты передаются в формате `YYYY-MM-DD`, а временные метки — в формате
RFC3339 и UTC.

## Сервис и авторизация

| Метод | Endpoint | Описание                                                                     |
|---|---|------------------------------------------------------------------------------|
| `GET` | `/api/health` | Проверяет доступность и готовность api-service-сервиса.                          |
| `GET` | `/api/health/live` | Проверяет, что процесс api-service работает. |
| `GET` | `/api/health/ready` | Проверяет PostgreSQL, Kafka и pet-state-service. |
| `POST` | `/api/app/auth/request-otp` | Создаёт пользователя при необходимости и открывает шаг входа по коду.        |
| `POST` | `/api/app/auth/verify-otp` | В рамках MVP принимает любой непустой код и создаёт JWT-сессию пользователя. |
| `GET` | `/api/app/auth/me` | Определяет текущего пользователя по JWT.                                     |

## Питомец

| Метод | Endpoint | Описание                                                         |
|---|---|------------------------------------------------------------------|
| `GET` | `/api/v1/pet` | Получает прогресс, счастье и cd действий питомца.                |
| `PATCH` | `/api/v1/pet` | Изменяет имя питомца.                                            |
| `POST` | `/api/v1/pet/care` | Выполняет действие `STROKE` или `FEED` и повышает счастье.       |
| `GET` | `/api/v1/pet/levels` | Получает список уровней питомца и доступных наград.              |
| `GET` | `/api/v1/pet/ws` | Открывает WebSocket-соединение для обновлений прогресса питомца. |
| `POST` | `/api/v1/pet/mvp/leaves` | Начисляет 200 листьев для демонстрации механик MVP.              |
| `POST` | `/api/v1/pet/level-rewards/{rewardId}/claim` | Забирает награду, связанную с достигнутым уровнем питомца.       |
| `POST` | `/api/v1/pet/chests/open` | Открывает сундук и списывает необходимое количество листьев.     |

Для `PATCH /api/v1/pet` передаётся новое имя питомца, а для WebSocket токен можно
передать через заголовок `Authorization` или query-параметр `token`.

Для ухода используется единое тело `{"type":"STROKE"}` или `{"type":"FEED"}`.
Поглаживание даёт 20, кормление — 35 единиц счастья. У каждого действия отдельный
cooldown 6 часов, а счастье линейно уменьшается от 100 до 0 за 72 часа.

## Награды

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/app/rewards` | Получает персональные награды пользователя, сгруппированные по категориям. |
| `GET` | `/api/app/rewards/{rewardId}` | Получает подробную информацию о конкретной награде пользователя. |
| `POST` | `/api/app/rewards/{rewardId}/redeem` | Использует обычную персональную награду; аренды из магазина применяются автоматически и не redeem-ятся. |

В этот список также попадают купленные в магазине миски и лежанки. Для таких
наград `itemType` равен конкретному типу предмета из каталога, `source` равен `SHOP`, а `expiresAt`
содержит точное время окончания аренды в UTC. Просроченные аренды сохраняются
в истории с соответствующим статусом.

## Магазин

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/v1/shop` | Возвращает полный каталог из шести мисок и лежанок со ссылкой на изображение, категорией, ценой, уровнем доступа и сроком аренды. |
| `GET` | `/api/v1/shop-images/{fileName}` | Раздаёт изображение предмета магазина без авторизации. |
| `POST` | `/api/v1/shop/{itemId}/purchase` | Покупает предмет за листья и активирует его на срок из каталога. |

В магазине одновременно действует не более одной миски и одной лежанки. Повторная
покупка того же предмета продлевает срок; замена активного предмета другого вида
требует `confirmReplacement: true`. Все сроки передаются в UTC.

## Ежедневные задания

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/v1/tasks` | Получает четыре задания текущего дня и их прогресс. |
| `GET` | `/api/v1/tasks/progress` | Получает количество выполненных заданий за текущий день. |
| `POST` | `/api/v1/tasks/record` | Записывает действия пользователя для обновления прогресса заданий. |
| `POST` | `/api/v1/tasks/{taskId}/claim` | Забирает награду за выполненное задание. |

Метод `POST /api/v1/tasks/record` принимает список событий с полями `taskId`,
`type` и `count`. Поле `taskId` необязательно: задание можно определить по его
типу.

Поддерживаемые типы заданий: `VIEW_LISTINGS`, `ADD_TO_FAVORITES`,
`PUBLISH_LISTING`, `BOOST_LISTING`, `LEAVE_REVIEW`, `COMPLETE_DEAL` и
`ORDER_WITH_DELIVERY`.

## Ежедневная сводка

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/v1/daily-report` | Получает итоги активности пользователя за текущий день. |
| `GET` | `/api/v1/daily-report/ws` | Открывает WebSocket-соединение для обновлений ежедневной сводки. |

WebSocket сразу отправляет актуальный снимок сводки, затем публикует события
`DAILY_REPORT_UPDATED` после изменений. JWT передаётся через заголовок
`Authorization` или query-параметр `token`.

## Еженедельный вход

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/v1/weekly-login` | Получает состояние наград за вход в текущей календарной неделе. |
| `POST` | `/api/v1/weekly-login/activity` | Засчитывает активность пользователя за текущий день. |
| `POST` | `/api/v1/weekly-login/claim` | Забирает доступную награду за вход за текущий день. |

Методы `POST /api/v1/weekly-login/activity` и `POST /api/v1/weekly-login/claim`
вызываются без тела запроса.

Награда рассчитывается как `baseRewardLeaves × (0.5 + happiness / 100)` и
округляется до ближайшего целого.
Если сервис состояния временно недоступен, weekly-login остаётся доступным и
использует базовую награду с множителем `1.0`.

## Внутренние события

| Метод | Endpoint | Описание |
|---|---|---|
| `POST` | `/api/internal/v1/users/{userId}/events` | Принимает подтверждённые события активности от доверенного сервиса Авито. |

Метод принимает список событий с полями `eventId`, `type`, `count` и
`occurredAt`.
