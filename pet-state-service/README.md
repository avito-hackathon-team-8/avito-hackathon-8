# Pet State Service

Внутренний Go-сервис состояния Коробыша. Он хранит счастье питомца, применяет
действия ухода, контролирует cooldown и публикует изменения в Kafka через
transactional outbox.

## Правила

- начальное счастье — 100;
- без ухода оно линейно уменьшается до 0 за 72 часа;
- `STROKE` добавляет 20, `FEED` — 35 единиц;
- у каждого типа действия отдельный cooldown 6 часов;
- действие при полном счастье отклоняется и не запускает cooldown.

Тело операции ухода:

```json
{"type":"STROKE"}
```

Для идемпотентного повтора передаётся необязательный `Idempotency-Key` длиной
до 128 символов. Ключи и результаты хранятся 7 дней.

## Доставка событий

Состояние и запись `pet_state_outbox` сохраняются в одной транзакции. Publisher
доставляет событие `PET_STATE_CHANGED` в topic `pet-state-events-v1` с ключом
`userId`; повторная доставка допустима. Publisher резервирует события lease-ом,
поэтому несколько реплик не публикуют одну строку одновременно. Каждая реплика
api-service использует собственную consumer group и отправляет клиенту
`PET_STATE_UPDATED`; дубли от at-least-once доставки фильтруются по `eventId`.
