## Стили и интерфейс

- Используй существующую систему стилей проекта: цвета, размеры, типографику, spacing tokens и готовые компоненты.
- Не добавляй произвольные значения, если в проекте существует подходящий token.
- Учитывай desktop- и mobile-состояния.
- Сохраняй доступность: используй семантическую разметку, labels, focus states и keyboard navigation.
- Не заменяй реальные assets плейсхолдерами без необходимости.
- Соблюдай принятую в проекте структуру CSS/SCSS и порядок свойств.
- Разделяй логические группы CSS/SCSS-свойств пустой строкой.
- Перед завершением задачи запускай:

  - `npm run lint:styles:fix` — автоматическое форматирование и сортировка стилей;
  - `npm run lint:styles` — итоговая проверка Stylelint.

- Не отключай правила Stylelint и не добавляй `stylelint-disable` без обоснованной технической необходимости.
- После автоисправления проверяй, что порядок shorthand- и longhand-свойств не изменил поведение стилей.
