# Shop API scenarios

Black-box e2e-сценарии публичного API магазина. Тесты обращаются к запущенному
Compose api-service по HTTP и создают изолированных пользователей в PostgreSQL.

Проверяются:

- авторизация для каталога и покупки;
- полный каталог и персональные статусы `ACTIVE`, `LOCKED`, `AVAILABLE`;
- покупка предмета с пустым необязательным телом и списание листьев;
- появление аренды среди наград пользователя;
- продление того же предмета ещё на три дня;
- обязательное подтверждение замены активной миски;
- независимая одновременная аренда миски и лежанки;
- ошибки уровня, баланса, неизвестного предмета и некорректного JSON;
- отсутствие списания листьев при отклонённых операциях.

## Запуск

```sh
make up
cd api-service
RUN_API_SERVICE_E2E=1 GOCACHE="${TMPDIR:-/tmp}/avito-go-build-cache" go test ./test/shop -count=1 -v
```

Для обращения к другому экземпляру API можно задать `SHOP_API_BASE_URL`.
